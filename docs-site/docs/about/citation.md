# Cite Pad-Lattice

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23777302.svg)](https://doi.org/10.5281/zenodo.23777302)

To cite Pad-Lattice as a project, use the **all-versions DOI**:

> Rueda, M. (2026). *Pad-Lattice: A Visual Protocol for AI Agent Control on Physical
> and Virtual Surfaces* [Software]. Zenodo. https://doi.org/10.5281/zenodo.23777302

For reproducibility, cite the version you used instead. Version **0.2.0** has
the DOI [10.5281/zenodo.23777303](https://doi.org/10.5281/zenodo.23777303).
Zenodo provides BibTeX and other citation formats for each record.

Machine-readable project metadata is in
[`CITATION.cff`](https://github.com/mrueda/pad-lattice/blob/main/CITATION.cff).
