# Roadmap

Current priorities:

- Finish testing and publishing the desktop installers.
- Improve usability through feedback from desktop, phone, and tablet users.
- Validate experimental Launchpad profiles with hardware testers.

Other controllers and agent integrations can follow as contributors and
testing hardware become available.

Share feedback in the [issue tracker](https://github.com/mrueda/pad-lattice/issues).
For hardware testing, see [Device Testing](../technical-details/device-testing.md).
