# Changelog

## 0.2.0 - 2026-10-26

- Desktop app for Linux and macOS: connect existing Codex CLI conversations,
  MIDI controllers, and paired browsers without launching another terminal.
- Experimental Elgato Stream Deck support; hardware testing pending.
- Light/dark themes, live audio, saved preferences, QR/PIN pairing, and device
  disconnect/reconnect controls.
- Updated Codex CLI integration; fixed stale sessions and Demo/Show interference
  with live controls.
- Safe diagnostics, bundled dependency notices, and simpler visual documentation.

## 0.1.0 - 2026-07-20

- First release: control multiple Codex CLI sessions through MIDI or a paired
  browser, using colors, glyphs, and request-specific actions.
- Launchpad Pro Mk1 support; experimental Mini Mk3 and Pro Mk3 profiles.
- Guided Demo, audiovisual Show, and optional audio feedback.
